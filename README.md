# 小银杏 · 东北财经大学 AI 校园助手

面向 **AI 高校建设场景** 的对话式智能助手，覆盖 **校园政策、课程安排、业务流程、材料审批查询** 四大场景。
形象取自东北财经大学校庆吉祥物「小银杏」——一枚金黄色的银杏叶，寓意「坚韧沉着」。

- **大模型**：智谱 GLM-4.7-Flash（`glm-4.7-flash`），**主模型限流/超时时自动降级**到备用模型（`GLM_MODELS` 可配置）
- **多模态**：支持发送**图片**（`glm-4.6v-flash` 视觉理解）、**文件**（PDF/Word/TXT 文本提取）、**语音**（浏览器语音识别）
- **文件下载**：可下载校历、表格等附件（内置校历 + 自动采集附件链接）
- **向量模型**：智谱 `embedding-3`（2048 维）
- **知识库**：分级 RAG（L0 路由 → L1 双路召回 → L2 精排），爬取门户/教务处通知政策并自动增量入库
- **形态**：电脑版（响应式 Web）+ 手机版（微信小程序，可融入现有小程序）

## 一、系统架构

```

│ 电脑版 Web   │   │ 微信小程序   │
│ (web/)      │   │(miniprogram)│
└──────┬──────┘   └──────┬──────┘

                │                                │
     ┌──────────┴───────────┐          ┌─────────▼────────┐
     │ 分级 RAG 知识库        │          │ 采集 Agent 自主循环 │
     │ L0 意图路由/元数据过滤  │◄─────────│ 目标→规划→执行→检查 │
     │ L1 BM25 + 向量双路召回 │          │ 门户/教务处/各部门  │
     │ L2 分数融合 + 精排     │          │ 通知政策智能入库    │
     │                       │          └──────────────────┘
     └──────────┬───────────┘
                │
        ┌───────▼────────┐
        │ GLM-4.7-Flash  │
        │ 生成式回答(带引用)│
        └────────────────┘
```

### 分级 RAG（召回策略）

| 层级 | 名称 | 做法 |
|---|---|---|
| **L0** | 意图路由 + 元数据过滤 | 规则关键词把问题映射到「主题分类 + 受众(学生/教师)」，粗粒度缩小候选空间；未命中自动全库召回，不丢召回 |
| **L1** | 双路召回 | ① BM25 关键词精确匹配（中文按字二元组切分）② 向量语义相似（embedding-3）；各自归一化后加权融合（向量可用时 6:4 偏向语义） |
| **L2** | 精排 + 去重 | 按融合分排序，按文档去重，输出 top-k 并附引用来源；可选 LLM 精排（`ENABLE_RERANK`） |

**容错**：向量服务不可用时自动降级为纯 BM25，保证系统始终可用。

### 采集 Agent（自主采集闭环）

后台定时触发「目标 → 规划 → 执行 → 检查」的 Agent 循环（`crawler/agent.py`）：

1. **目标**：上班时段每天两次（默认 9:00、15:00，`COLLECT_HOURS` 可配）采集与学生/教师相关、可能被问询的操作性政策通知；
2. **规划**：按站点/栏目拆解采集任务，明确调用工具（爬虫 `crawl_column`/`crawl_files`、大模型判别、知识库入库）与验收标准；
3. **执行**：爬取目标站点 → 大模型**判别相关性**（过滤获奖报道等无关内容）→ 按分类入库；仅对「新增或内容变化」的文档做判别，避免重复调用大模型；
4. **检查**：校验完整性（应采通知覆盖率）+ 一致性（入库文本与原文抽样比对），通过才算一次成功循环。

**容错**：大模型不可用时自动降级为规则判定（过滤 `news` 类），保证系统始终可用。详情页统一 `content_{id}.html`，以 `content_id` 去重、文本哈希增量更新；内置 20 篇「高校高频业务流程」参考知识，首次启动即离线可用。

## 三、快速开始

### 1. 一键启动（推荐，Windows）

直接双击项目根目录的 **`启动小银杏.bat`**：

- 首次运行会自动安装依赖；
- 服务启动后会自动打开浏览器 `http://127.0.0.1:8000/`；
- 使用期间保持该窗口开启，**关闭窗口即停止服务**；下次再双击即可再次启动。

> 若服务已在运行，再次双击会直接打开浏览器，不会报端口占用。

### 2. 命令行启动

```bash
cd backend
pip install -r requirements.txt
python run.py
```

访问 `http://127.0.0.1:8000/` 即打开电脑版（手机浏览器访问同一地址即手机版）。

> 配置见 `backend/.env`：`GLM_API_KEY` 必填（已预置）、`GLM_MODEL=glm-4.7-flash`、`EMBEDDING_MODEL=embedding-3`。

### 2. 主要接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/chat` | 对话（`stream:true` 走 SSE 流式，`false` 返回 JSON，供小程序用） |
| GET | `/api/kb/stats` | 知识库统计 |
| GET | `/api/kb/documents` | 文档列表（分类/搜索） |
| POST | `/api/crawl/run` | 手动触发采集入库 |
| GET | `/api/crawl/status` | 采集状态 |
| GET | `/api/suggestions` | 快捷提问 |

### 3. 微信小程序

用「微信开发者工具」打开 `miniprogram/` 目录；将 `app.js` 中 `baseUrl` 改为后端地址（开发时可勾选「不校验合法域名」，上线需 HTTPS 备案域名）。

## 四、AI 助手功能调研与完善（需求 4）

### 4.1 市面 AI 助手功能矩阵（调研结论）

| 能力维度 | 主流功能 | 小银杏落地情况 |
|---|---|---|
| 对话能力 | 多轮上下文、流式输出、Markdown 渲染 | ✅ 已实现 |
| 知识增强 | RAG 检索增强、引用来源可溯 | ✅ 分级 RAG + 来源标注 [1][2] |
| 个性化 | 多会话管理、历史记录 | ✅ 最近对话（Web 本地存储） |
| 领域服务 | 政策/流程/审批查询、快捷入口 | ✅ 快捷提问 + 分类路由 |
| 内容安全 | 敏感词过滤、免责声明 | ⚠️ 已加免责声明，敏感词待接 |
| 多模态 | 图片理解、语音输入 | 📋 规划（GLM 支持多模态） |
| 主动服务 | 通知订阅、消息推送 | 📋 规划（基于自动采集推送） |
| 运营分析 | 问答日志、满意度、热点分析 | 📋 规划 |

### 4.2 已实现的丰富功能

1. **流式对话 + Markdown**：逐字输出、标题/列表/代码块/链接渲染；
2. **引用可溯源**：每个回答标注来源编号与出处链接，可信可查；
3. **意图路由可视化**：界面显示本次回答命中的知识分类（🔎 政策/办事流程…）；
4. **快捷提问**：高频业务一键提问，降低使用门槛；
5. **知识库面板**：实时展示文档/切片/分类数量，可一键「立即更新知识库」；
6. **双端一致**：电脑版 + 手机版（含小程序）同一套后端。

### 4.3 后续迭代建议（Roadmap）

- **语音输入 / 语音播报**（Web Speech API + 小程序录音）；
- **图片/文件理解**（对接 `glm-4.7v-flash` 多模态，识别证明材料、成绩单截图）；
- **个性化用户画像**：登录后按学院/年级推荐通知，差异化解答；
- **订阅推送**：基于自动采集的新政策定向推送给关注该主题的用户；
- **多智能体**：政策问答、教务流程、图书馆、后勤分领域子助手；
- **反馈与运营面板**：点赞/点踩、热点问题聚合、问答质量监控。
