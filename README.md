# 🌿 小银杏 · 校园 AI 助手

面向校园服务场景的对话式 AI 助手，帮助师生快速获取校园政策、课程安排、办事流程与材料审批等信息。

## ✨ 主要功能

- 💬 **智能问答**：自然语言提问，回答附带可追溯的参考来源
- 📚 **校园知识库**：覆盖政策制度、通知公告、办事流程、考试安排、奖助贷、毕业学位等
- 📎 **多模态输入**：支持图片、文件、语音提问
- 📄 **文件获取**：一键获取校历等常用附件
- 🔄 **知识自动更新**：定时采集学校官网最新通知政策并入库
- 📱 **多端使用**：Web 网页 + 微信小程序

## 🚀 快速开始

### 方式一：GitHub Codespaces（推荐，零配置）

1. 点击仓库右上角 **Code → Codespaces → Create codespace on main**
2. 等待环境自动加载，完成后即可在新窗口弹出项目。
3. 如耐心等待至全部加载完成后网址依旧未能自动弹出，大概率是窗口弹出被您的浏览器阻止。点击下方的 **端口（Ports）** ，用浏览器打开“转发地址”，即可打开项目。

### 方式二：本地运行

```bash
cd backend
pip install -r requirements.txt
python run.py
```

浏览器访问 <http://127.0.0.1:8000>

### 微信小程序

用微信开发者工具打开 `miniprogram/` 目录，把 `app.js` 里的 `baseUrl` 改成你的后端地址即可。
